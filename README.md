# Практическая работа №2 — CSS, адаптивная вёрстка и SCSS

Адаптивный каталог «Учебный магазин» на HTML и SCSS: панель фильтров, сетка из 18 карточек, информационный блок со сводной таблицей и подвал. Стили написаны в SCSS (переменные, partial-файлы, миксины, функции, циклы) и скомпилированы в `css/styles.css`. JavaScript не используется — фильтрация работает на CSS (`:checked` + `:has()`).

**Технологии:** HTML5, CSS Grid, Flexbox, Sass (Dart Sass, синтаксис SCSS, модули `@use`).

## Запуск

Готовый CSS уже лежит в репозитории, поэтому для просмотра достаточно открыть `index.html` в браузере.

Пересборка стилей из SCSS (нужен Node.js 18+):

```bash
npm install          # установит sass
npm run build        # разовая сборка: scss/styles.scss → css/styles.css
npm run watch        # режим наблюдения: пересборка при каждом сохранении .scss
```

Без `package.json` то же самое: `npx sass scss/styles.scss css/styles.css --no-source-map` (добавьте `--watch` для наблюдения).

## Структура

```
index.html                  — разметка каталога
css/styles.css              — скомпилированный CSS (не редактируется вручную)
scss/
  styles.scss               — главный файл, только подключает partial-файлы
  _variables.scss           — цвета, радиус, отступы (из theme.json), ширины, брейкпоинты, карта категорий
  _functions.scss           — rem(), space(), radius()
  _mixins.scss              — container, focus-ring, surface, down, tint
  _base.scss                — сброс, типографика, ссылки, custom properties
  _layout.scss              — шапка, Grid-раскладка страницы, подвал
  components/
    _button.scss  _badge.scss  _card.scss
    _catalog.scss _filters.scss _info.scss
images/                     — product-01..03.svg (из dataset/assets)
data/                       — catalog.csv, theme.json (копии)
dataset/                    — исходные файлы задания без изменений
package.json                — команды build / watch
```

## Использование dataset

| Файл | Где используется |
|---|---|
| `catalog.csv` | 18 карточек (`name`, `category`, `price`, `rating`); `id` → `id="product-N"` и артикул; `category` → бейдж и атрибут `data-category` для фильтра; `rating ≥ 4.5` → атрибут `data-top`; сводная таблица «О каталоге» (кол-во, мин./макс./средняя цена, средний рейтинг) |
| `theme.json` | `accent`, `surface`, `background`, `text`, `radius: 14`, `space: 16` → переменные в `scss/_variables.scss` |
| `assets/product-0X.svg` | Изображения карточек: товар N получает картинку `product-0((N−1) mod 3 + 1)` |

Маршрут данных: `catalog.csv` / `theme.json` → значения перенесены в `index.html` и `_variables.scss` → SCSS компилируется в `css/styles.css` → браузер отображает страницу.

## Раскладка и адаптивность

- **Grid страницы** (`.layout`): `260px | 1fr`, области `sidebar / content / info`.
- **Grid каталога** (`.catalog`): `repeat(auto-fill, minmax(220px, 1fr))` — число колонок меняется само.
- **Flexbox**: шапка, меню, тело карточки, группы фильтров, подвал.
- **Breakpoint 1 — 1024px** (`$bp-lg`): раскладка перестраивается в одну колонку, фильтры уходят над каталогом и выстраиваются в строку.
- **Breakpoint 2 — 600px** (`$bp-sm`): плотнее карточки (минимум 150px → 2 колонки на телефоне, меньше отступы и шрифт), компактная навигация.
- Проверено в Responsive Mode на 375, 768 и 1440px: горизонтальной прокрутки нет (широкая таблица прокручивается внутри своего блока).

## Ошибочное / пустое состояние

Если выбрать «Инструменты» + «Только от 4.5», товаров нет (максимум рейтинга в категории — 4.4). Вместо пустой сетки показывается блок «Ничего не найдено» (`.catalog-empty`). Под каталогом CSS-счётчик выводит число видимых карточек. Кнопка «Сбросить фильтры» (`type="reset"`) возвращает все 18.

## Что изменилось на отдельных шагах

- **Шаг 8 (вложенность).** Стили сгруппированы по БЭМ-блокам через `&__element` и `&--modifier`; глубина вложенности не больше трёх уровней (например `.site-nav → &__link → &:hover`).
- **Шаг 9 (mixin).** Повторяющиеся наборы свойств вынесены: `surface` (фон+рамка+радиус) используется в карточке, фильтрах, инфоблоке и пустом состоянии; `focus-ring` — в ссылках и кнопках; `down($bp)` — во всех медиазапросах; `container` — в контейнере.
- **Шаг 10 (функции).** `space($n)` считает отступы от `space: 16` из theme.json, `radius($k)` — от `radius: 14`, `rem($px)` — перевод в rem. Цикл `@each` по карте `$categories` генерирует и цвета бейджей, и правила фильтров — новая категория добавляется одной строкой.
- **Шаг 12 (сетка).** Карточки на `auto-fill + minmax`: 3 колонки на 1440, 3 на 768, 2 на 375.
- **Шаг 13 (брейкпоинты).** 1024px — перестройка раскладки, 600px — плотность карточек и навигация.

## SCSS-переменная и CSS custom property

- **SCSS-переменная** (`$accent`) существует только во время компиляции: Sass подставляет значение, в итоговом CSS её нет, изменить её в браузере нельзя. Зато с ней работают функции и вычисления Sass (`color.adjust`, `math.div`).
- **CSS custom property** (`--accent`) попадает в итоговый CSS, видна в DevTools, наследуется по DOM и может меняться в браузере (медиазапросом, классом, из JS). В проекте `--accent` и `--radius` объявлены в `:root` из SCSS-переменных (`_base.scss`).

## Зачем partial-файлы

Файлы с `_` в начале не компилируются отдельно — их подключает `styles.scss` через `@use`. Так стили разделены по ответственности (переменные, база, раскладка, компоненты), их проще искать и менять, а значения темы хранятся в одном месте и не дублируются.

## Сценарий проверки

1. Открыть `index.html` — 18 карточек, «Показано товаров: 18».
2. Выбрать «Книги» → 6 карточек; добавить «Только от 4.5» → 3.
3. Выбрать «Инструменты» при включённом рейтинге → блок «Ничего не найдено».
4. «Сбросить фильтры» → снова 18.
5. DevTools → Responsive: 1440 / 768 / 375 — нет горизонтальной прокрутки, на 768 фильтры над каталогом.
6. Поменять `$accent` в `_variables.scss`, выполнить `npm run build` — цвет меняется в кнопках, ценах, ссылках и фильтрах.
